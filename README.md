# NGULU FOTO

Responsive single-page website for NGULU FOTO, a photography studio near UiTM Machang, Kelantan. Built with plain HTML, CSS, and JavaScript so it can be served as a static site (including GitHub Pages).

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Before publishing

- Add the studio's verified WhatsApp number and social profile URLs.
- Confirm business hours, pricing, exact map pin, and replace the illustrative gallery images with NGULU FOTO's own portfolio.
- The current Google Maps and Waze buttons search the supplied nearby location; they are not a verified exact studio pin.

All prices are intentionally presented as inquiry-based because no confirmed price list was provided.
